Mouse Controller Support

Need help connecting? Start with the setup steps, then try the fixes below. If you're still stuck, email us.

Requirements

  • Both apps installed: MouseController for iPhone (App Store) and MouseController for Mac (Mac App Store), both free
  • iPhone with iOS 17.6 or later and Mac with macOS 14.6 or later
  • Both devices on the same Wi-Fi network or Personal Hotspot
  • The Mac companion app running, with Accessibility allowed
  • The newest version of both apps. iPhone version 1.2 and later uses encrypted pairing and won't connect to older Mac apps.

Getting the Mac app

  • The Mac app is free on the Mac App Store, where it is called MouseController.
  • The welcome tour in the iPhone app has a button that sends the link to your Mac with AirDrop. The Mac App Store opens as soon as the link does.

Get it on the Mac App Store

My Mac doesn't appear in the list

  • The iPhone app shows a short checklist when no Mac is found. Go through it first.
  • Make sure the Mac app is running: look for the cursor icon in the menu bar.
  • Check that both devices are on the same network. On a hotspot, make sure the Mac joined the hotspot of this iPhone.
  • On iPhone, turn on Settings → Privacy & Security → Local Network → MouseController.
  • As a fallback, tap Enter IP address manually and type the IP address shown in the Mac app.

"That code didn't work"

  • Type the code into the boxes exactly as the Mac app shows it.
  • After 5 wrong attempts the Mac waits 30 seconds before accepting a new try.

It connects, but the cursor doesn't move

  • Accessibility permission is missing or out of date, which often happens after installing a new version. In System Settings → Privacy & Security → Accessibility, remove MouseController with −, add it again, then restart the Mac app. If you used the older download from our website before, remove that entry too and keep only the Mac App Store app.

The cursor feels too slow or too fast

  • Open Settings in the iPhone app and change Pointer speed and Acceleration. Haptics and every gesture can be adjusted there too.

I have the older Mac app from the website

  • Quit it from its menu bar icon, move MouseControllerMac from Applications to the Bin, and install MouseController from the Mac App Store. It updates itself from then on.
  • If the iPhone asks for a code, pair again with the one the new app shows.
