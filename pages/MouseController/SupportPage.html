Mouse Controller Support

Need help connecting? Start with the setup steps, then try the fixes below. If you're still stuck, email us.

Requirements

  • iPhone with iOS 17.6 or later and Mac with macOS 14.6 or later
  • Both devices on the same Wi-Fi network or Personal Hotspot
  • The Mac companion app running, with Accessibility allowed
  • The newest version of both apps. iPhone version 1.2 and later uses encrypted pairing and won't connect to older Mac apps.

Download the Mac app

My Mac doesn't appear in the list

  • Make sure the Mac app is running: look for the cursor icon in the menu bar.
  • Check that both devices are on the same network. On a hotspot, make sure the Mac joined the hotspot of this iPhone.
  • On iPhone, turn on Settings → Privacy & Security → Local Network → MouseController.
  • As a fallback, tap Enter IP address manually and type the IP address shown in the Mac app.

"That code didn't work"

  • Enter the code exactly as the Mac app shows it. The dash is optional.
  • After 5 wrong attempts the Mac waits 30 seconds before accepting a new try.

It connects, but the cursor doesn't move

  • Accessibility permission is missing or out of date, which often happens after installing a new version. In System Settings → Privacy & Security → Accessibility, remove MouseControllerMac with −, add it again, then restart the Mac app.

macOS says the app can't be opened

  • Download the app only from our official releases. If macOS still blocks it, open System Settings → Privacy & Security and click Open Anyway.
